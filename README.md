# Paradise Nursery

Paradise Nursery is an online plant shopping application built with React. It allows users to browse houseplants by category, view plant names and prices, and add plants to a shopping cart.

## Features

- Browse houseplants across multiple categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities and remove items.
- View the total cost of items in the cart.

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- Vite

## Project Purpose

This project demonstrates the development of a plant shopping website with product listings, navigation, and shopping cart functionality.
